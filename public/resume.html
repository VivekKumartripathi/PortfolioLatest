Flagship Case Studies

CASE 1 · FLAGSHIP — Multi-tenant HubSpot CRM Integration | ASP.NET Core · C# · HubSpot API · Associations API · BullMQ · Redis
  • Problem: Each client has its own HubSpot portal, and child records (Deals) cannot be linked before their parents (Companies, Contacts) exist.
  • Built: An ASP.NET Core Web API layer with client-scoped token connections, dependency-ordered sync with association linking, and per-client queues with retries and backoff.
  • Impact: One client’s rate limit or bad record no longer blocks the others, and every child record lands under the correct parent.
CASE 2 · DATA ENGINEERING — Parquet Data Lake: S3 to Snowflake | FastAPI · PyArrow · AWS S3 · Snowflake · SFTP
  • Problem: Partner data arrived as inconsistent CSV/JSON files over SFTP and through APIs, and was slow to query.
  • Built: Separate FastAPI services for ingest, validation and transformation; partitioned Parquet on S3; Snowflake loads through external stages.
  • Impact: One repeatable path from raw partner file to queryable Snowflake table, with raw files retained on S3 for replay.
CASE 3 · APPLIED AI — Claude + MCP Enterprise AI Layer | Claude · FastMCP · OpenAI GPT · Python
  • Built: MCP tools giving Claude natural-language access to enterprise data, with token-based auth and per-user visibility enforced in the tool layer; LLM-assisted classification and mapping.
CASE 4 · DSA — Algorithmic Data Mapping Framework | Python · Hash Maps · Blocking · RapidFuzz · SQL Server
